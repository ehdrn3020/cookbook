# Evolution

> 작성일: 2026-04-14

- Schema evolution
	- 스키마 업데이트는 메타데이터 변경이므로 업데이트를 수행하기 위해 데이터 파일을 다시 작성할 필요가 없음
- Partition evolution
	- 파티션 사양을 변경하면 이전 사양으로 기록된 기존 데이터는 변경되지 않고 그대로 유지
	- 새로운 데이터는 새로운 레이아웃에 기록됩니다. 각 파티션 버전의 메타데이터는 별도로 관리
- Sort order evolution
	- 정렬 순서를 변경하더라도 이전 순서로 기록된 기존 데이터는 변경되지 않음
