# snapshot.mode 종류

> 작성일: 2025-11-12

`snapshot.mode`는 Debezium 커넥터가 시작할 때 기존 테이블 상태를 어떻게 처리할지 결정하는 설정

- no_data : 테이블 스키마만 캡처하고(스냅샷 워크플로는 밟지만) 스냅샷 레코드(`op:"r"`)는 생성하지 않음. 즉시 스트리밍
- recovery : 스키마 히스토리 토픽이 유실/손상/비정상 팽창했을 때, 소스 DB에서 스키마 정보를 다시 읽어 히스토리 토픽을 재구성하는 복구 스냅샷을 수행
- when_needed : 커넥터가 시작할 때 조건부로만 스냅샷을 수행
