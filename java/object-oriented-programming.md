# 객체지향 언어 : 다형성 / 추상화 / 인터페이스

> 작성일: 2025-11-15

- 클래스
	- 정의 : 데이터 + 함수
	- 변수 : 클래스변수(클래스가 메모리에 올라갈 때) + 인스터스 변수(인스턴스가 생성될 때)
- 호출 스택 : 싱글스레드에서는 스택 맨 위의 하나만 실행, 나머지 스택은 대기 중
- 매개변수 : 기본형, 참조형 매개변수("같은 객체"의 내용이 바뀜 / 클래스 또는 배열의 타입을 사용)

```javascript
// 기본형 매개변수
void foo(int a, double b) { ... }

// 참조형 매개변수
void bar(String s, int[] arr, MyClass obj) { ... }
```

- Static / Instance 메서드 : iv 사용여부가 가장 큰 차이점
